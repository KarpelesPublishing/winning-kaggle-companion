Chapter 60

Multi-Target Learning

Compare the primary metric with and without the auxiliary task, and let relatedness and weight decide.

An auxiliary target feeds gradients into a shared layer. One demonstration measures held-out accuracy on a scarce main target, with and without a dense auxiliary target, as the auxiliary target's relatedness and loss weight change.

Every example is constructed for teaching. Its numbers come from running the chapter activity's code, not from a competition result.

1. Held-out main-target accuracy with and without an auxiliary task

Demonstration 1 of 1

Held-out main-target accuracy with and without an auxiliary task

When does a dense auxiliary target improve a scarce main target on new rows, and how much does the loss weight matter?

The auxiliary gradient reaches the shared layer, so it shapes the features the main head reads. When the auxiliary target is built on the same latent features, its 1,200 dense rows teach the shared layer features that 120 main labels cannot, and a larger weight helps more. As its signal drifts away from the main target's, those extra rows teach features the main head does not need, and the gain shrinks toward noise. The weight multiplies whatever the auxiliary task teaches, useful or not.

At relatedness 0.7 the single-task model scores R-squared 0.574 on new rows. With the auxiliary task at weight 3 it scores 0.657, and 0.657 - 0.574 = 0.083 (standard error 0.018, better in 92% of 12 replicates). The gain is more than two standard errors, so the auxiliary task earns its place. Weight 1 changes the score by +0.030 and weight 0.3 by +0.020.

Worked steps

  1. Single-task model: R-squared 0.574 on 4,000 new rows.
  2. Weight 3: 0.657 - 0.574 = 0.083, with standard error 0.018.
  3. Weight 1: 0.604 - 0.574 = 0.030.
  4. Weight 0.3: 0.594 - 0.574 = 0.020.

Use the idea

Train the multi-target model and a single-task reference under the same stopping rule, compare the primary metric on rows neither used, and keep the auxiliary task only if the gain is clear, then tune its weight.

Where the conclusion applies

Constructed data and a small numpy network standing in for the chapter's PyTorch trunk. The main-target stopping step comes from only 30 rows, which is noisy, and the size of the gain differs between problems, so the chart shows each replicate. No gradient alignment is measured: a small or negative change is not proof of gradient conflict, which is the chapter's own caution. Under two other seeds the weight-3 gain at relatedness 1.0 stayed clear (about 0.07) and the related settings kept beating the unrelated ones, but the weight-3 gain at 0.7 fell to about 0.03, so the exact sizes and the order of 1.0 and 0.7 are not stable.
