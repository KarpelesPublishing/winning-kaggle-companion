1. Tracing outer-validation label contamination

Demonstration 1 of 1

Tracing outer-validation label contamination

If you change only a validation row's target, which training encodings of the same category change?

Excluding a row's own target is necessary but not the whole validation boundary: every feature used to train the model must exclude the outer-validation targets. Perturbing C's target exposes the dependency without fitting a model. The nested encoding does not move, which is the property you want to verify.

A and B are outer-training rows and C and D are outer-validation rows of the same category, y_X is the target of row X, e_A^unsafe is row A's encoding built from the validation rows, and e_A^nested is its encoding built only from training row B.

Predict first. C is a validation row. You flip its target from 1 to 0 and recompute the encodings of training row A. Which ones change?

With C's target at 1, row A's unsafe encoding is (1 + 0) / 2 = 0.50. Setting C's target to 0 would give 0.00, so a validation label alone moves a training feature by 0.50 - 0.00 = 0.50. The nested encoding stays at 1.00 either way.

Worked steps

  1. C's validation target is set to 1; the other targets are fixed (A is 0, B is 1, D is 0).
  2. Unsafe encoding of A: (1 + 0) / 2 = 0.50.
  3. Same encoding with C's target at 0: 0.00.
  4. Nested encoding of A uses only B: 1.00 in both settings.
  5. Validation labels each encoding depends on: 2 (unsafe) and 0 (nested).

Use the idea

Freeze the outer split first and build every category statistic inside the outer training slice, cross-fitting training rows internally. Then perturb outer-validation targets and confirm that no training feature changes.

Where the conclusion applies

A and B are training rows and C and D are validation rows of one category, with targets A = 0, B = 1 and D = 0. No smoothing is applied; smoothing can shrink the contamination without removing the dependency. The example shows a dependency, not how large its effect on a score would be.

Check your understanding: Row A's unsafe encoding is 0.5 when C's target is 1. What is it when C's target is 0, and how many validation labels does it depend on?
It is (0 + 0) / 2 = 0.0, and it depends on two validation labels (C and D) either way. The nested encoding depends on none, so it stays at 1.
