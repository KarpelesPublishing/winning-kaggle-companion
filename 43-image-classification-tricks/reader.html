1. Two label-smoothing conventions, two different targets

Two label-smoothing conventions, two different targets

Do two label-smoothing conventions produce the same target?

A smoothing coefficient is incomplete without its target convention. Both targets here are valid probability vectors, but they put different mass on the correct class, so the same epsilon gives different cross-entropy for the same prediction.

Scroll sideways for the whole equation →

epsilon is the smoothing coefficient, t the three-class target with class 0 true, p the fixed predicted probabilities (0.7, 0.2, 0.1), and CE the cross-entropy of a target against p. One convention spreads epsilon over the two wrong classes; the other mixes the hard label with a uniform distribution over all three.

At epsilon 0.1 the wrong-classes-only convention puts 1 - 0.1 = 0.9 on the true class, while the uniform mix puts 1 - 0.1 + 0.1 / 3 = 0.9333 there. Against p = [0.7, 0.2, 0.1] the cross-entropies are 0.5166 and 0.4633, so the same epsilon names two different training objectives.

Worked steps

  1. Fixed prediction p = [0.7, 0.2, 0.1]; the true class is class 0 and epsilon = 0.1.
  2. Wrong classes only: target 0.9000, 0.0500, 0.0500, so 1 - 0.1 = 0.9 on class 0.
  3. Uniform mix: target 0.9333, 0.0333, 0.0333, so 1 - 0.1 + 0.1 / 3 = 0.9333 on class 0.
  4. Cross-entropies: 0.5166 for wrong classes only and 0.4633 for the uniform mix.

Use the idea

Write the exact target construction beside any smoothing, Mixup or CutMix setting, save it with the checkpoint, and judge the trained model on the competition metric, not the displayed loss.

Where the conclusion applies

Three classes, true class 0, one fixed prediction and a controlled epsilon. No model is trained, so this shows only that the targets and loss values differ, not which convention trains a better model.

Check your understanding: Which epsilon in the uniform mix gives the same target as the wrong-classes-only convention at epsilon 0.1?
Epsilon 0.15. The uniform mix puts 1 - 0.15 + 0.15 / 3 = 0.9 on the true class and 0.05 on each wrong class, matching wrong classes only at 0.1, and both have cross-entropy 0.5166. In general epsilon_uniform = 1.5 x epsilon_wrong for three classes.
