When an auxiliary loss helps or cancels the primary step

How does the auxiliary-loss weight change a shared parameter when the auxiliary task agrees with the primary task or opposes it?

More targets help only when their shared learning signal supports the primary task. One shared parameter makes that visible: an aligned auxiliary adds to the primary step, while a conflicting one subtracts from it and can cancel or reverse it as its weight grows.

With w = 0.5 the conflicting auxiliary has combined gradient -1 + 0.5 x 1 = -0.50, so the parameter moves 0 - 0.1 x (-0.50) = 0.050. The aligned auxiliary adds to the primary gradient (combined -1.50) and reaches 0.150. The conflicting step shrinks as w grows toward 1 and reverses past it. One local gradient step does not show that the tasks are incompatible over training.

Worked steps

  1. Primary gradient at theta = 0 is -1; the aligned auxiliary gradient is -1, the conflicting one is +1.
  2. Aligned combined gradient: -1 + 0.5 x (-1) = -1.50.
  3. Conflicting combined gradient: -1 + 0.5 x 1 = -0.50.
  4. Conflicting step: 0 - 0.1 x (-0.50) = 0.050.
  5. Updated parameter: aligned 0.150, conflicting 0.050.
  6. Primary loss after, from 0.5 before: aligned 0.361, conflicting 0.451.

Use the idea

Measure the primary and auxiliary gradients on the same shared parameters, and compare a smaller auxiliary weight or partial sharing when they point apart. Reject an auxiliary if the primary score falls reproducibly.

Where the conclusion applies

A one-parameter analytic quadratic model with one step, not a trained network. A drop in primary performance does not by itself identify gradient conflict, and one local gradient cannot show long-run incompatibility.

Check your understanding: At what weight does the conflicting auxiliary give no update, and what is the primary loss then?
At w = 1.0: the combined gradient is -1 + 1.0 x 1 = 0, so the parameter stays at 0 and the primary loss stays at 0.5.
