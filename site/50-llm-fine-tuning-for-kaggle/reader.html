1. LoRA rank, parameter count and the update

Demonstration 1 of 1

LoRA rank, parameter count and the update

How does changing LoRA rank change the adapter parameter count and the constructed matrix update?

The activity builds a four-by-three frozen matrix and explicit rank-r factors, then adds the alpha / r scaled product B A to it. The adapter has r x (3 + 4) trainable parameters. At these tiny dimensions the count passes the full matrix at rank 2, which shows adapters are not always smaller.

Scroll sideways for the whole equation →

W is the frozen four-by-three matrix, B (4 x r) and A (r x 3) the adapter factors, alpha the fixed scaling constant 2, r the rank, and d_in and d_out the input and output sizes (3 and 4).

With 3 inputs and 4 outputs, rank 1 trains 1 x 7 = 7 adapter parameters, 12 - 7 = 5 fewer than the full matrix. The update is scaled by alpha / r = 2 / 1 = 2.0000, so changing the rank also changes the scale; state which convention is held fixed.

Worked steps

  1. Rank r = 1: A is 1 x 3 and B is 4 x 1.
  2. Adapter parameters: 1 x 7 = 7.
  3. Full matrix parameters: 4 x 3 = 12.
  4. Scale: alpha / r = 2 / 1 = 2.0000.
  5. First updated entry: 1 + 0.1000 = 1.1000.

Use the idea

Before inserting LoRA, inspect the named attention modules and verify the trainable parameter count and optimizer coverage. Record rank, scaling and target modules, and compare against the base model under matched settings.

Where the conclusion applies

The factors are deterministic illustrative numbers, not trained values, and alpha stays at 2. Only this tiny matrix is computed: the full count d_in x d_out grows with the product of the sizes and the adapter count only with their sum, so the comparison changes with the dimensions. Parameter efficiency does not guarantee a quality gain.

Check your understanding: With alpha fixed at 2, what is the scale at rank 3, and is the adapter larger than the full matrix?
The scale is 2 / 3 = 0.6667. The adapter has 3 x 7 = 21 parameters, which is 21 - 12 = 9 more than the 12 in the full matrix.
