Budgeting weights and headroom for a vision-language model

How large a 4-bit vision-language model passes an aggregate memory budget once you add runtime headroom?

Four-bit weights take half a byte per parameter, which gives a lower bound on memory before quantization metadata, activations, vision inputs and caches. The worksheet adds a stated overhead and compares the total with an aggregate budget. It is arithmetic, not a measurement.

M_total is the estimated total memory in GiB, P the parameter count (billions times 10^9), b = 4 bits per weight, o = 6 GiB of assumed runtime overhead, and B = 30 GiB of aggregate memory. Dividing by 8 converts bits to bytes and by 1024^3 converts bytes to GiB.

At 32 billion parameters the raw 4-bit weights take 14.90 GiB, so 14.90 + 6.00 = 20.90 GiB with the assumed overhead. Against the 30.00 GiB budget that is 30.00 - 20.90 = 9.10, so the aggregate check passes. Even so, a pass says nothing about fitting on each device.

Worked steps

  1. Raw weights: 32 billion x 4 bits / 8 = 16.0 billion bytes, which is 14.90 GiB.
  2. Add the assumed overhead: 14.90 + 6.00 = 20.90 GiB.
  3. Compare with the budget: 20.90 against 30.00 GiB, a margin of 9.10.
  4. Aggregate check: pass. Serial time for the 5,000-image worksheet is 25 minutes at every size.

Use the idea

Compute the raw-weight bound first, then smoke-test an actual load and peak memory on the exact hardware. Profile end-to-end throughput including any second opinion, and keep headroom for long inputs.

Where the conclusion applies

Four-bit raw weights, an assumed 6 GiB overhead and a 30 GiB aggregate budget. Passing does not guarantee per-device placement, kernels or throughput on two GPUs. The 25 minute serial runtime for 5,000 images uses one assumed rate and does not change with model size, so it is not a latency estimate for any checkpoint.

Check your understanding: At 72 billion parameters, by how many GiB does the estimate exceed the 30 GiB budget?
Raw weights are 33.53 GiB and the total is 33.53 + 6.00 = 39.53 GiB, so it exceeds the budget by 39.53 - 30.00 = 9.53 GiB.
