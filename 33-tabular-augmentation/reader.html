Data Augmentation for Tabular Data

1. What Mixup preserves and what it breaks

Demonstration 1 of 1

What Mixup preserves and what it breaks

What does Mixup preserve, and which joint constraints can it violate?

Interpolation builds a mathematical training example, so ask which properties it keeps. Numeric features stay between the source values, and the indicators still sum to one. Most mixed rows, however, no longer describe a single observed category, and the soft target needs a loss that accepts probability targets.

Indicators 0.40 + 0.60 = 1.00, so they still sum to one, yet the row is no longer a single observed category. Income lands between the two source rows: 10 <= 22.0 <= 30.

Worked steps

  1. Mixing weight on row A: 0.40; on row B: 1 - 0.40 = 0.60.
  2. Income: 0.40 * 10 + 0.60 * 30 = 22.0.
  3. Indicators: [0.40, 0.60], which sum to 1.00.
  4. Soft class target: [0.40, 0.60].
  5. Valid one-hot category: no.

Use the idea

Write down one joint constraint from your dataset and test whether interpolation respects it. Use one-hot or weighted-loss targets for classes, never interpolated class IDs, and keep validation rows untouched.

Where the conclusion applies

Two nonnegative rows with mutually exclusive category indicators and different class targets. A fractional category can be a deliberate regularizer, but it is not an observed customer, and this shows no training benefit.

Check your understanding: For which weights on the 0.05 grid is the mixed row still a valid one-hot category?
Only weights 0 and 1, where the mixed row equals one of the original rows. Every weight strictly between gives a fractional indicator vector.
