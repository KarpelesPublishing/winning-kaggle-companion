The Process Mindset

Recompute the logged gap before reading meaning into it.

A recoverable experiment log connects a hypothesis to its data, folds, outputs and keep or reject decision. One demonstration recomputes the gap between leaderboard and CV loss for four logged versions.

Recompute the logged CV-LB gap

Which logged versions have a CV-LB gap large enough to investigate, and what does a flag actually tell you?

A useful log lets you recompute the comparison you will need tomorrow. Each gap here is the leaderboard loss minus the CV loss, so a positive gap means the public loss is worse. Lowering the tolerance flags more versions, but a flag only says which runs deserve inspection.

LB_i and CV_i are the leaderboard and cross-validation losses of logged version i, g_i is their gap, tau is the gap tolerance, and f_i is 1 for a flagged version and 0 otherwise.

The recency version has LB 0.02250 and CV 0.02210, so the gap is 0.02250 - 0.02210 = 0.00040. At tolerance 0.00030, 1 of 4 versions are flagged. A flag means look at the run, not that a feature overfit.

Worked steps

  1. baseline: 0.02480 - 0.02450 = 0.00030 (not flagged).
  2. blend: 0.02210 - 0.02230 = -0.00020 (not flagged).
  3. feature: 0.02240 - 0.02215 = 0.00025 (not flagged).
  4. recency: 0.02250 - 0.02210 = 0.00040 (flagged).
  5. Versions with |gap| above 0.00030: 1.

Use the idea

Add run ID, baseline ID, metric direction, split identity and data and code versions to your ledger, and compute each delta in code instead of typing it. Write a next action for each flagged row: keep the champion, repeat a paired comparison, or audit a suspected leak.

Where the conclusion applies

Four illustrative versions with a loss where smaller is better; for a metric that rewards larger values the same subtraction means the opposite. A flag is not proof of overfitting, and the tolerance is a screening choice, not a threshold with statistical meaning.

Check your understanding: At tolerance 0.0002, how many versions are flagged, and why is the blend version not one of them?
Three. The blend gap is 0.0221 - 0.0223 = -0.0002, so its size is 0.0002, which equals the tolerance and is not strictly above it. The other three gaps (0.0003, 0.00025 and 0.0004) are all larger.
