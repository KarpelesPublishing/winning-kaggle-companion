Chapter 41

Online Learning

Update only on labels that have been released.

A stream changes which information is available for each prediction, so keep an availability clock beside the event clock. One demonstration shows how label delay shrinks the set of usable outcomes.

1. Which labels exist before the next prediction

Which labels exist before the next prediction

Which labels are available before the next prediction?

An online update needs an availability clock as well as an event clock. Counting events by observation time says all six rows can train the model, but labels arrive a delay later, so fewer are usable. Change the delay and compare the two counts.

E is the set of six event times 2 to 7, d the label delay, and t_p the prediction time, 8. An outcome is usable only if its release time, event time plus d, is strictly earlier than t_p.

Predict first. The model predicts at time 8 from events at times 2 to 7, and each outcome is released 3 time units after its event. How many outcomes can the update use?

By observation time all 6 events precede t = 8, but with a delay of 3, 3 outcomes are released before the prediction: 6 - 3 = 3 outcomes are excluded. An earlier observation is not yet a labeled training example.

Worked steps

  1. Events occur at times 2, 3, 4, 5, 6, 7; the prediction is made at t = 8.
  2. By observation time, all 6 events are earlier than 8.
  3. Each outcome is released at event time + 3. Usable only if event time + 3 < 8.
  4. Usable events: 2, 3, 4, which is 3 of 6.
  5. Outcomes excluded as not yet released: 6 - 3 = 3.

Use the idea

Store observation time, prediction origin and label-release time separately, then replay the stream: predict each batch first and ingest only outcomes whose release precedes that prediction.

Where the conclusion applies

Six events at integer times 2 to 7, one fixed delay for every outcome, and a prediction at time 8 with a strict rule that release time must be earlier than the prediction. A same-time reveal would need an explicit ordering rule.

Check your understanding: With a delay of 5, which event times are usable, and how many outcomes are excluded?
Only the event at time 2, released at 2 + 5 = 7, which is before 8. The event at 3 is released at 3 + 5 = 8, not strictly before the prediction, so 6 - 1 = 5 outcomes are excluded.
