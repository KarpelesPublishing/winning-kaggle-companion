Advanced Feature Selection

Compare each feature with its own null before pruning it.

Feature selection needs a comparison point and an independent check. One demonstration moves a null percentile cutoff and shows which of three invented features survive.

Every example is a constructed teaching example. Its results describe the declared inputs of the chapter activity, not a measured competition gain.

1. Which features clear their own null importance cutoff

Demonstration 1 of 1

Which features clear their own null importance cutoff

As the null percentile rises, which features still beat what chance importance looks like for them?

Raw importance needs a comparison point before it can guide pruning. Each feature is compared with importances it reached when the target relationship was broken, so equal raw importance does not mean equal evidence. A higher percentile asks for a stricter margin over that feature's null.

At the 75th percentile 1 of 3 features survive (feature 0: 8 vs 5.0; feature 1: 10 vs 11.0; feature 2: 3 vs 3.0). The closest call is feature 2: 3 - 3.0 = 0.0, and a feature is kept only when that gap is above zero. Survival nominates a feature for an independent ablation; it is not proof of signal.

Worked steps

  1. Percentile cutoff: 75.
  2. Feature 0: real 8, cutoff 5.0, kept (8 - 5.0 = 3.0).
  3. Feature 1: real 10, cutoff 11.0, dropped (10 - 11.0 = -1.0).
  4. Feature 2: real 3, cutoff 3.0, dropped (3 - 3.0 = 0.0).
  5. Features kept: 1 of 3.

Use the idea

Build the null from permutations that respect time and group structure, fit it inside the outer training data, then confirm a few candidate removals with paired ablations on the same folds.

Where the conclusion applies

Three features, with invented real importances and five invented null values each. This illustrates a screening cutoff, not fitted importances, and it does not control multiple-testing error or certify signal.

Check your understanding: Feature 1 has real importance 10 and a null median of 10. Why is it dropped even at the 50th percentile?
The rule needs real importance strictly above the cutoff. At the 50th percentile the cutoff is 10.0, and 10 > 10.0 is false.
